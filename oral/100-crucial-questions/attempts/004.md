# The 100 Crucial Questions in Psychiatry — Provisional Attempt 004

English-first draft. Questions only; no model answers. This iteration applies a stricter rule: each main question should test one clinical entity, one presentation, one drug/class, or one defensible comparison. Breadth is pushed into selective follow-ups rather than overloaded headlines.

Coverage checks used for this iteration: the current `Psych` oral-exam material; Crash Course Psychiatry, 5th ed., textbook material only through PDF page 268; and the previously agreed board-exam coverage logic. This remains provisional.
