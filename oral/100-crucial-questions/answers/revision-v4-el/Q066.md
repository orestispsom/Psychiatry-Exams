# Q66. Πώς αξιολογείτε υπερβολική ημερήσια υπνηλία και πιθανή ναρκοληψία;

## Άξονας ανάκλησης
1. **Επιβεβαίωση πραγματικής sleepiness** → 2. **insufficient sleep/OSA/drugs/circadian/depression** → 3. **cataplexy + REM phenomena** → 4. **PSG/MSLT** → 5. **type 1 vs type 2** → 6. **specialist treatment**

## Πρότυπη προφορική απάντηση
Πριν διαγνώσω narcolepsy, αποδεικνύω ότι πρόκειται για πραγματική **excessive daytime sleepiness** και αποκλείω συχνότερα αίτια: insufficient sleep, obstructive sleep apnoea, sedating medications, circadian disorder, depression/medical illness και άλλες hypersomnolence disorders.

Η narcolepsy χαρακτηρίζεται από ακατανίκητη υπνηλία ή sleep attacks. Η **cataplexy** — αιφνίδια απώλεια μυϊκού τόνου με διατηρημένη συνείδηση, συχνά πυροδοτούμενη από συναίσθημα — δείχνει έντονα προς narcolepsy type 1. Sleep paralysis και hypnagogic/hypnopompic hallucinations είναι υποστηρικτικά αλλά όχι υποχρεωτικά.

Narcolepsy type 1 ορίζεται στο κατάλληλο diagnostic framework από cataplexy και/ή hypocretin/orexin deficiency. Type 2 δεν έχει cataplexy ούτε επιβεβαιωμένη hypocretin deficiency.

Σε κατάλληλους ασθενείς, standard objective pathway είναι **overnight polysomnography (PSG) ακολουθούμενη από Multiple Sleep Latency Test (MSLT)**. Δεν χρειάζεται να απομνημονεύσω αριθμητικό CSF hypocretin threshold αν δεν ζητηθεί.

Η θεραπεία είναι specialist και συνδυάζει scheduled sleep/behavioural measures με wake-promoting και, όπου χρειάζεται, cataplexy-targeted pharmacotherapy. Δεν απαιτείται εξαντλητικός drug catalogue στην προφορική απάντηση.

## Βασικά σημεία για τις εξετάσεις
- Πρώτα αποκλείω insufficient sleep, OSA, drugs και circadian causes.
- **Cataplexy → ισχυρά narcolepsy type 1**.
- PSG → MSLT είναι standard objective pathway.
- Sleep paralysis/hypnagogic hallucinations υποστηρίζουν αλλά δεν απαιτούνται.

## Συχνές παγίδες / παγίδες εξεταστή
- Fatigue = sleepiness.
- Narcolepsy πριν αποκλειστεί insufficient sleep/OSA.
- Απαίτηση της «τετράδας» σε κάθε ασθενή.
- Excessive drug-detail αντί diagnostic pathway.

## Πιθανή ερώτηση εξεταστή: Τι είναι REM sleep behaviour disorder;
Η **REM Sleep Behaviour Disorder (RBD)** είναι dream-enactment behaviour λόγω απώλειας της φυσιολογικής REM atonia και υποστηρίζεται/επιβεβαιώνεται με polysomnographic **REM sleep without atonia**. Προτεραιότητα είναι injury prevention και review provoking drugs/other sleep disorders. Immediate-release melatonin ή clonazepam παραμένουν conditionally supported symptomatic options σε κατάλληλους ασθενείς. Η ισχυρή σχέση με τωρινές ή μελλοντικές **alpha-synucleinopathies**, όπως Parkinson disease και DLB, είναι προγνωστικά σημαντική. Δεν υπάρχει καθιερωμένη neuroprotective θεραπεία.
